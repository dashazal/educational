## Цель проекта
Создание виртуального прототипа системы управления микроклиматом «Умный офис» в среде GNS3, включая настройку сетевой инфраструктуры, контейнеризацию сервисов и базовую эмуляцию работы IoT-устройств.


## Роли устройств в топологии

| Устройство | Роль | Описание |
|-----------|------|----------|
| **WIN** (Windows Server 2019) | Рабочее место администратора | Управление сетью, мониторинг, удалённое подключение к другим узлам |
| **IOT** (RED OS 8-1) | IoT-шлюз серверной | Запуск Node-RED, имитация датчиков температуры/влажности и вентилятора |
| **CTRL** (RED OS 8-2) | Контроллер | Сбор данных с IoT-устройств, координация работы системы, Git-репозиторий |
| **MON** (RED OS 8-3) | Мониторинг | Визуализация показаний датчиков, веб-интерфейс для пользователя |
| **DB** (RED OS 8-4) | База данных | Хранение истории показаний температуры, влажности и состояния вентилятора (SQLite) |
|**REDOS8-5**  | Маршрутизатор | Меж-VLAN маршрутизация, NAT, шлюз для всех подсетей |
| **Switch1**  | Коммутатор | Сегментация сети на VLAN, коммутация трафика |
 
## Используемые технологии
- **GNS3** — эмулятор сети
- **Cisco IOS** — маршрутизатор и коммутатор
- **RED OS 8** — отечественная ОС на базе Linux
- **Windows Server 2019** — рабочая станция администратора
- **Node-RED** — визуальное программирование IoT-потоков
- **draw.io** — схемы помещений
- **Git + GitHub** — контроль версий
