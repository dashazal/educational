## Цель проекта
Создание виртуального прототипа системы управления микроклиматом «Умный офис» в среде GNS3, включая настройку сетевой инфраструктуры, контейнеризацию сервисов и базовую эмуляцию работы IoT-устройств.


## Роли устройств в топологии

| Устройство | IP-адрес | Роль | Функция |
|-----------|------|----------|----------|
| **WIN** (Windows Server 2019) | `192.168.10.10` | Рабочее место администратора | Управление сетью, мониторинг, удалённое подключение к другим узлам |
| **IOT** (RED OS 8-1) | `192.168.30.4` | IoT-шлюз серверной | Запуск Node-RED, имитация датчиков температуры/влажности и вентилятора |
| **CTRL** (RED OS 8-2) | `192.168.20.13` | Контроллер | Сбор данных с IoT-устройств, координация работы системы, Git-репозиторий |
| **MON** (RED OS 8-3) | `192.168.20.10` | Мониторинг | Визуализация показаний датчиков, веб-интерфейс для пользователя |
| **DB** (RED OS 8-4) | `192.168.20.30` | База данных | Хранение истории показаний температуры, влажности и состояния вентилятора (SQLite) |
|**REDOS8-5**  | `192.168.10.1` | Маршрутизатор | Меж-VLAN маршрутизация, NAT, шлюз для всех подсетей |
| **Switch1**  | `-` | Коммутатор | Сегментация сети на VLAN, коммутация трафика |
 
## Используемые технологии
- **GNS3** — эмулятор сети
- **Cisco IOS** — маршрутизатор и коммутатор
- **RED OS 8** — отечественная ОС на базе Linux
- **Windows Server 2019** — рабочая станция администратора
- **Node-RED** — визуальное программирование IoT-потоков
- **draw.io** — схемы помещений
- **Git + GitHub** — контроль версий
